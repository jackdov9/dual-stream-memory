PAPER

Abstract

Long-horizon vision-language-action (VLA) control requires access to task-relevant visual evidence and compact temporal context. We present dual-stream memory that separates task-conditioned retrieval from task-agnostic recurrent compression. A dense retriever locates relevant frames and patches, while a Gated DeltaNet summarizes a stride-sampled causal history. Progress regression and action-conditioned reconstruction of past visual features supervise the compressed state. Linear multi-scale fusion combines coarse context and fine detail within 512 fixed spatial slots. Separate policy readouts integrate this spatial memory with one temporal token. Controlled RoboMME ablations evaluated frame retrieval, spatial fusion, and temporal readout. The complete model achieved [TBD]% task success, exceeding FrameSamp+Modul by [TBD] percentage points, and achieved [TBD]% average success across four Piper tasks. These results support separate spatial and temporal memory interfaces within the evaluated tasks and history lengths.

ARCHITECTURE

Two streams, one policy

Only retrieval is conditioned on the task text. Compression runs on a stride-sampled visual prefix.

Spatial stream

Dense retrieval and linear fusion

512 slots

The retriever scores front-view history with the task goal and selects 32 frames. Linear multi-scale fusion fills 512 SigLIP slots from aligned 2×2, 4×4, and 8×8 grids.

Temporal stream

Gated DeltaNet compression

1 token

A six-layer Gated DeltaNet compresses a stride-3 visual prefix into ct. Separate cross-attention reads the patch memory and this token. Progress and reconstruction heads are training-only.
